# AppDawn — Landing Page Promocional

Landing page para promocionar **AppDawn**: un boilerplate open source completo para construir productos digitales.

🔗 **URL**: https://appdawn-promo.envs.teros.ai

## ¿Qué es AppDawn?

AppDawn te da los planos básicos para montar cualquier aplicación. Incluye:

- **App Móvil** — React Native + Expo (iOS, Android, Web)
- **Landing Page** — Next.js + Tailwind CSS
- **Backoffice** — React + Vite + Tailwind
- **Backend API** — NestJS + Prisma + PostgreSQL

Todo preconfigurado con las mejores prácticas.

## Stack Técnico de esta Landing

- Next.js 16 + TypeScript
- Tailwind CSS v4
- Framer Motion (animaciones)
- Lucide React (iconos)
